# Smart Library System

Welcome to the **Smart Library System**! This project is a modern, intuitive library management application built as a JavaFX assignment. It streamlines day-to-day library operations, offering an efficient graphical user interface and reliable local data management.

## 🌟 Features
- **Book Inventory Management:** Add, update, delete, and search for books within the catalog.
- **User Management:** Track library members, their details, and borrowing history.
- **Borrow & Return Workflow:** Seamlessly issue books to users and process returns with status tracking.
- **Modern UI:** A clean, responsive graphical interface built entirely with JavaFX.
- **Persistent Storage:** Reliable data saving and retrieval using a local database instance.

## 💻 Tech Stack
- **Language:** Java
- **GUI Framework:** JavaFX
- **Build Tool:** Maven (`pom.xml`)
- **Database:** Local Database (`smartlibrary.db`)
- **IDE:** IntelliJ IDEA (`.idea` configuration included)
